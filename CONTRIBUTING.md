# Contributing

Internet Hands welcomes improvements to fetching, parsing, monitoring, storage, provenance, and platform adapters.

## Ground rules

- Preserve raw-source provenance.
- Keep network operations bounded by default.
- Add tests for policy and parser changes.
- Do not add credential theft, access-control bypass, CAPTCHA defeat, exploit delivery, stealth/evasion, or malware features.
- Platform adapters must document authentication and rate-limit requirements.
